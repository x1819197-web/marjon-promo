# MARJON REEL v2 — что сделано и как это воспроизвести

Версия 2 собрана по лучшим открытым практикам моушн-дизайна «кодом» (GitHub) и по жёсткой сетке отступов.
Итог: **`marjon_reel_v2_9x16.mp4`** — 1080×1920, 30 fps, 39.92 с, H.264 + AAC, `-14 LUFS`, со вшитыми караоке-субтитрами.

## 1. Что именно взято из GitHub (и почему именно это)

| Источник | Что взяли | Почему |
|---|---|---|
| **howseen-ai/claude-motion-design** (самый полный «боевой» скилл: HTML + Playwright + ffmpeg) | конвейер `brief → beat map → stills → seek(t) → render → ffmpeg → QA`; **запрет CSS-transition/таймеров**; `visibility`, а не только `opacity`; парал­лельный рендер чанками; захват кадра = `fonts.ready` + 2×`requestAnimationFrame`; финальный энкод `bt709 + yuv420p`, crf 16–18; SFX по измеренным пикам; `loudnorm −14 LUFS`; вставки реального b-roll вместо генерации | это ровно наш кейс: продуктовый промо на 40 с, 9:16, без After Effects |
| **remotion-dev/skills → `remotion-best-practices`** | «один источник истины — номер кадра»: всё из `useCurrentFrame`; **никаких** `Math.random`, `setTimeout`, CSS-анимаций в композиции; всегда `clamp` у interpolate; входы на **spring**, не на линейных слайдах | мы реализовали это на чистом JS: `seek(t)`, `spring()`, `kf()`, `clamp01` |
| **frankxai/awesome-motion-design-agent-skills → `motion-director` + `motion-quality-rubric`** | рубрика приёмки по 7 критериям (Purpose / Timing / Hierarchy / Brand fit / Accessibility / Performance / Implementation), порог 18+ из 21 | по ней и правили итерации (см. §5) |
| **emilkowalski/skills → `animate`** | логика выбора: сначала цель, потом свойство, потом кривая и длительность (а не «анимируем всё») | отсюда: анимируются только 4 типа (вход, акцент, счётчик, камера) |
| **Ассеты — Mixkit** (бесплатно для коммерции, без атрибуции) | b-roll ресторана/кухни/кассы + музыка + SFX | скилл прямо рекомендует Mixkit как замену Suno/Soundly; ключи к Pexels/Unsplash требуются, Mixkit работает без ключей |
| **Real-UI вместо стоковых скриншотов** | макеты модулей сняты из вашего же `landing/` (Playwright, активируя панели) | это единственный способ показать **свой** интерфейс, а не «псевдо-UI» от видео-генератора |

Чего сознательно **не** делали: AI-генерация интерфейса (Veo/Kling рисуют нечитаемый UI и врут в цифрах), шаблонные генераторы (InVideo/Canva) — получается сток-ролик.

## 2. Отступы: сетка, по которой всё стоит

```
поля по бокам        96 px  (8.9 cqw)      ← var(--m)
вертикальный ритм    24 px  (2.2 cqw)      ← var(--g)
safe-top            176 px  (верх UI)      ← var(--safe-top)
safe-bottom         480 px  (низ UI)       ← var(--safe-bottom), Instagram заголовки/кнопки
субтитры            470 px от низа, 1–2 строки, 72–85 px от верха полосы
```

Правила, которые теперь соблюдаются во всех 7 кадрах:
1. **Ничего не заходит в нижние 480 px** (кроме субтитров) — раньше телефон и кнопка CTA наезжали друг на друга и на подпись Instagram.
2. **Один вертикальный ритм** — каждый блок отстоит от другого кратно 24 px, а не «на глаз».
3. **Иерархия размеров**: hero 123 px → h1 99 → h2 80 → h3 56 → body 36 → label 27 → micro 23. Ровно 7 ступеней, ни одного «случайного» размера.
4. **Ничего не стоит на месте > 0.6 с**: у каждой сцены постоянный микро-дрейф камеры (0.8–1.2 %), въезд на пружине, «панорама» по ключевым кадрам.
5. **Без чёрных кадров на стыках**: уходящая сцена не гаснет — новая проявляется поверх (кросс-фейд 130 мс), проверено на кадрах 9.95 / 13.55 / 24.35 / 28.55.
6. **Субтитры — часть кадра** (прожигаются), с караоке-подсветкой по словам; на светлой сцене автоматически переключаются на тёмные буквы.

### Как править и пересобирать

```bash
# 1) текст/тайминг/сетка — в promo.html (SCENES, CUES, CLIPS, CSS-переменные --m/--safe-*)
# 2) звук — HITS в build.py (время, файл, громкость)
# 3) проверка кадров без полного рендера:
python3 render.py probe 5.2 12.0 20.5 31.0
# 4) полный рендер (3 чанка, ~20 мин на 2 ядрах):
python3 render.py full A && python3 render.py full B && python3 render.py full C
# 5) сборка:
python3 build.py encode
```
Предпросмотр без рендера: открыть `promo.html`, `Space` — играть, `←/→` — по кадрам, `G` — показать сетку и безопасные зоны.

## 5. Что уже отбраковано на итерациях (рубрика 18+/21)

| Итерация | Проблема | Как исправлено |
|---|---|---|
| v1 | цена 500 000 в озвучке против 100 000 на экране | в v2 одно число, в кадре и в субтитре |
| v1 | статичные кадры «презентации» | живое видео + камера + врезки |
| v2-α | субтитры наезжали на кнопки/телефон | сетка safe-bottom 480 px, все блоки пересчитаны |
| v2-β | чёрные кадры на стыках сцен | кросс-фейд, уходящая сцена не гаснет |
| v2-γ | на PiP-врезке терялись карточки боли | врезки уменьшены до 37×19 cqw и сдвинуты вправо |
| v2-δ | на светлом кадре белые субтитры не читались | авто-переключение на тёмные |
| v2-ε | последняя панель модулей обрывалась | слот = длина сцены / 6, последняя держится |

Осталось за вами: **записать узбекский голос** под 17 реплик (`CUES` в promo.html) — тайминг субтитров уже подогнан под этот ритм, после записи подгоним точнее. И подтвердить цену (500 000 или 100 000) — тогда пересборка занимает 20 минут.
